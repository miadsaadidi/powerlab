## 1. Operating Protocol

For each scheduled URL:
1. Open [Google Search Console](https://search.google.com/search-console) for property `sc-domain:powelab.org` (or `https://www.powelab.org/`).
2. Paste the exact canonical URL in the top search box: **"Inspect any URL in 'powelab.org'"** (*"Inspecter n'importe quelle URL"*).
3. Wait for Google to retrieve live data from index.
4. Click **"Request Indexing"** (*"Demander une indexation"*).
5. Confirm pop-up dialog (*"Indexing requested"* / *"Indexation demandée"*).
6. Check off the box in this file and note the date.

> **CRITICAL INVARIANT:** Never submit `https://powelab.org/...` (non-www). Always submit strictly canonical `https://www.powelab.org/...`.
